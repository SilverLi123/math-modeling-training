# Problem Analysis — 2025-CUMCM-C

## Deliverables

完整模型合同见 `题目分析报告.md`；术语和单位见 `术语表格.md`。当前实现范围仅为数据流水线与问题 1 的 LMM baseline。

## Sub-problem decomposition

- Q1：解释男胎 Y 浓度与孕周、BMI 等变量的纵向关系。
- Q2：仅依据事前 BMI 确定连续分组和推荐检测时点。
- Q3：加入事前多因素后重新估计达标概率并优化分组时点。
- Q4：依据 AB 标签判定女胎 T13/T18/T21 及总体异常。

## Relationships between sub-problems

Q1 提供浓度模型；Q2、Q3 将浓度/达标概率接入决策优化；Q4 是独立的不平衡分类任务。

## Independent baseline plan

Q1 先使用随机截距 LMM，之后以相同数据切分比较 GAMM。其余问题在 Q1 统计结构验证后实现。

## 2026-09-07 合同修订

Q1 先低复杂度加性平滑随机截距，交互、随机斜率与质控分别验证。Q2/Q3 冻结为直接观测达标的二项混合模型，面向新孕妇积分随机效应；共用风险与人数加权 DP，整个策略选择进入外层验证。18 组重复测序仅用于额外误差敏感性。Q4 先审查各标签独立阳性人数，总体异常主展示但保留染色体判定。

已完成 Q1 LMM/样条对比、Q2 概率校准与改进检验，以及 Q4 标签计数与总体 AB 标签的 Elastic-Net baseline。Q2 的决策门尚未通过，BMI 分组/DP 未执行；Q3 已完成固定协变量比较和模型依赖 DP 敏感性：无概率增益，分组切点不稳定；染色体级 Q4 仍待后续验证。
