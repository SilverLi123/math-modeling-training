# 重复测序尺度与额外噪声敏感性

18 组同日、同次抽血、同孕周重复检测来自 14 名孕妇，每组两次。对 logit(Y) 计算组内平方和，单次检测误差标准差估计为 `sqrt(总组内平方和/总自由度)=0.123745`。按14名孕妇重采样重复组2000次，尺度95%百分位区间为[0.081746, 0.167701]。该换算依赖同次技术误差独立同方差，不能把小样本尺度当作通用测量定律。

## 重拟合实验

按267名孕妇整体有放回抽样20次，为重复抽中的同一孕妇分配新的抽样槽位ID。每轮在原始logit浓度上叠加0、0.5、1、1.5倍上述尺度的正态噪声，保持4%阈值；同轮各尺度及Q2/Q3_basic共享抽样与标准噪声。0倍只评估样本组成变化，其他情景评估在已有观测噪声之上的额外扰动，不是去噪或潜在真实浓度估计。

全部160次模型拟合通过数值门限，0失败；保存640条四组约束下的条件策略。支持人数在Bootstrap中是抽样主体槽位数，重复抽中的原孕妇可重复贡献，不能描述为新增独立原始孕妇。

下表为每轮主体等权平均推荐孕周的20次模拟中位数及范围，不是单人的推荐孕周，也不是95%置信区间。

零额外噪声时已有很宽的重采样范围，因此不能把不稳定性全归因于测量误差；中位数未随噪声单调变化，不能推出“误差越大越早检测”等规律。20轮用于探索性敏感性，不足以精确估计尾部概率。11/25周边界解和外部代价权重的局限继续成立。

## 复现

```powershell
.\.venv\Scripts\python.exe -W error src/q23_measurement_sensitivity.py --repeats 20
.\.venv\Scripts\python.exe -W error src/summarize_measurement_sensitivity.py
```

两命令退出码0。`experiment.json`保存全部参数、诊断、失败列表、随机种子及输入哈希；`repeat_groups.csv`与`scale.json`记录误差估计；`policies.csv`为原始策略，`policies_collapsed.csv`合并相邻同时间组，`summary.csv`为模拟汇总。
