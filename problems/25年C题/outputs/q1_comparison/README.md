# Q1：LMM 与加性自然样条混合模型

本次为小规模模型验证，1082 条记录、267 名孕妇。两模型均为随机截距模型；样条是无惩罚自然三次回归样条混合模型，不宣称为自动平滑惩罚 GAMM。输入仅孕周、BMI；LMM 保留原有线性交互，样条版本为加性。此比较是两套候选规格的比较，不能把全部差异归因于非线性本身。

| 模型 | 行级 OOF RMSE | 行级 OOF MAE | 行级 OOF R² | 孕妇等权 RMSE |
|---|---:|---:|---:|---:|
| LMM | 0.514063 | 0.423210 | −0.030232 | 0.506284 |
| 加性样条混合模型 | 0.507167 | 0.415976 | −0.002776 | 0.500832 |

均为 logit 浓度尺度。外层沿用原五折孕妇划分，内层三折按孕妇等权 MSE 选择每个平滑项 df=3 或 4；中心化和结点均只在训练折拟合，未见孕妇只用固定效应预测。外层选中 df 为 3/4/4/4/4；全数据内层选出 df=3 用于展示效应，不用于回填 OOF。

样条行级 RMSE 降低约 1.34%；孕妇等权 RMSE 降低约 1.08%。配对孕妇 Bootstrap 的 RMSE 差（样条减 LMM）95% 区间为 [−0.014924, 0.001955]，跨零，因此不能确认稳定优势。区间来自 2000 次对已冻结 OOF 误差的孕妇级重采样，没有重新训练或重新选模型，不能代表完整训练流程的不确定性。

## 图表与图注

所有图为中文、可编辑 SVG 与 300 DPI PNG，灰度预览位于同目录 `_qa`。图表仅覆盖本次 Q1 实验，不代表全题编程终检。

1. [五折配对误差](../figures/q1_comparison/result_q1_comparison.png)：每条线连接同一验证折的两种模型，指标先在各孕妇内部平均平方误差，再跨孕妇等权平均并开方；五折不是五个独立实验。
2. [孕周效应](../figures/q1_comparison/result_q1_effect_gestational_week.png)：BMI 固定为样本中位数，展示全数据 df=3 模型固定效应预测。孕周较晚区域观测稀疏，不应把上翘理解为普遍生物规律。
3. [BMI 效应](../figures/q1_comparison/result_q1_effect_bmi.png)：孕周固定为样本中位数，BMI 两端区间较宽。底部短线为检测记录的边际分布，不代表二维组合都有支持。
4. [OOF 残差诊断](../figures/q1_comparison/process_q1_oof_diagnostics.png)：展示样条对未见孕妇的预测误差。Q–Q 尾部存在偏离；这些误差包含新个体差异，不等同于条件模型中的独立残差，不能据此单独判定条件正态假设。

两张效应图阴影为给定已选样条基的逐点 95% Wald 区间，不是孕妇级重拟合 Bootstrap、同时置信带或个体预测区间，也未调整模型选择不确定性；不能用于宣称最终显著性。

## 复现

在题目目录执行：

```powershell
.\.venv\Scripts\python.exe -W error src\run_q1_experiment.py
.\.venv\Scripts\python.exe -W error -m unittest discover -s src -p 'test_q1*.py' -v
```

第一条命令生成对比表、逐行 OOF、内层选择记录、效应源数据、四张图及 `results/q1_comparison_manifest.json`。该清单使用 skill 提供的清单生成器，绑定当前代码、合同和输出；旧 baseline 清单保留。

## 判断与下一步
