# 支撑材料说明

本目录的完整论文对应项目根目录的`完整论文.docx`和`rendered_paper.pdf`。数值结论由项目内的代码和附件重算得到，不依赖手工录入结果。

## 运行条件

- Python依赖见项目根目录`requirements.txt`；推荐使用`.venv\Scripts\python.exe`。
- 原始题目和附件保留在`data/raw/`，不得改写。运行前需保留其中的`附件.xlsx`。
- 从题目目录执行：

```powershell
.venv\Scripts\python.exe -W error src\run_paper_evidence.py
```

该入口依次重建四问的表、图和指标，并运行测试。运行时间取决于机器性能；Q2/Q3的主体重采样和数值积分是主要耗时步骤。

## 交付内容映射

| 论文内容 | 代码或结果位置 |
| --- | --- |
| 问题一混合模型与样条对照 | `src/q1_lmm_baseline.py`、`src/q1_spline_comparison.py`、`outputs/q1_comparison/` |

论文中的条件时点均绑定于已写明的阈值、风险权重、样本范围和观测支持约束；不应脱离这些条件解释为临床建议。
