# 图表契约

三图均为中文论文单图，Python，6 英寸宽、3.2–3.4 英寸高；SVG 与 300 DPI PNG，灰度预览。147 名孕妇、605 条记录，所有统计直接来自实验文件。

- raw_q4_positive_subjects：横条图显示独立阳性孕妇稀少（18/30/12/44）；类别可重叠，不能求和当独立样本总数，不加抽样误差棒。
- process_q4_calibration：散点图显示总体标签分箱预测与实际率的偏离；n 为各箱记录数，不是独立主体数。仅描述校准，稀疏高概率箱不用于校准成立的推断，不用连线暗示连续估计。
- result_q4_brier_intervals：点与区间图比较各标签模型相对训练阳性率基准的主体等权损失差；横线为 147 主体冻结 OOF 损失 2000 次 Bootstrap 的 95% 百分位区间，无重拟合、不校正多目标比较。负值表示损失降低，T21 未显示稳定改进。
