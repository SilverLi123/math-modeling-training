# Q2 非线性、嵌套校准与早期样本敏感性

本轮没有找到稳定优于线性未校准模型的方案，且早期可观测子样本的概率曲线变化明显。因此，决策门未通过，暂不进入 BMI 分组和风险函数/动态规划优化。

## 设计

- 沿用 4% 达标阈值及固定的五折孕妇外层划分，任何孕妇不跨训练与验证折。
- 比较线性孕周与 3 自由度自然三次样条孕周；两者都含线性首次 BMI 代理和孕妇随机截距。
- 校准截距与非负斜率只使用外层训练集中三折孕妇级 OOF 预测拟合，并按孕妇等权；外层验证标签完全不参与。
- 新孕妇概率通过 Gauss–Hermite 求积积分随机效应。Bootstrap 对冻结的外层 OOF 孕妇损失作 2000 次配对重采样，不含重拟合不确定性。
- 早期敏感性子集包含首条观测不晚于 12 周的 69 名孕妇，并保留这些孕妇的全部记录；它是选择机制敏感性检查，不是随机抽样对照。

## 样本外结果

| 模型 | 孕妇等权 Brier | 孕妇等权 Log-loss |
|---|---:|---:|
| 线性：未校准 | 0.111597 | 0.383614 |
| 线性：内层校准 | 0.112780 | 0.386106 |
| 孕周样条：未校准 | 0.111262 | 0.382298 |
| 孕周样条：内层校准 | 0.112308 | 0.383698 |

相对线性未校准模型，样条未校准的孕妇等权 Brier 差为 −0.000335，95% 配对 Bootstrap 区间 [−0.001346, 0.000645]；线性校准与样条校准的区间也都跨零。校准虽略降记录级 Log-loss，却提高孕妇等权 Brier，不能视为稳定改进。部分内层校准斜率落在合法的零边界，代码用投影梯度/KKT 条件核验；这也提示预测排序信号在部分折中较弱。

## 早期样本敏感性

在 BMI 28/32/36、11–20 周网格上，早期 69 人模型相对全样本模型的平均绝对概率差为：线性 0.04599、样条 0.05133；最大绝对差分别为 0.10487、0.10191。差异具有实际量级，表明重复检测进入样本的时点可能影响概率曲线，不能直接把全样本曲面解释成首次检测人群的可靠决策概率。

## 图表与文件

- `comparison.csv`：四种 OOF 概率的记录级与孕妇等权指标。
- `oof_predictions.csv`：逐记录外层 OOF 预测，可追溯到孕妇和折号。
- `calibration.csv`：固定概率箱中的记录数、孕妇数、预测均值与实际率。
- `early_sensitivity.csv`：全样本与早期 69 人模型的概率网格。
- `experiment.json`：拟合诊断、校准参数、Bootstrap 与敏感性摘要。
