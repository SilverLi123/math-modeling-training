# 有序 DP 分组×时点决策工具（纯算法；门控内使用）

## 用途与门控

本模块实现题目 Q2/Q3 所需的“按 BMI 有序分组 + 每组合适检测孕周”的联合决策算法：

- 输入：受试者 BMI（升序）、候选孕周网格、每名受试者在每孕周的**观测达标边际概率矩阵 p(w, BMI)**（由门控通过的概率模型提供）；
- 目标（情景化）：每组成本 = 组内人均 [ (1−p) + w_late·L(w) ]，其中 L(w) 为题目分段晚发现风险，w_late 为**情景参数**（不宣称数据可唯一确定）；
- 约束：至多 K 个连续 BMI 组；各组孕周沿 BMI 升序**非降**；可选组均覆盖率下限 coverage_q；
- 输出：分组边界、各组孕周、均值覆盖率、总成本；`pareto()` 在不同 w_late 下输出计划表供 Pareto 式权衡展示。

**门控（项目合同）**：本文件只是工具，不得在 Q2 概率模型通过决策门之前用于发布真实推荐时点。仓库内仅以合成数据测试与示例（`example.json`）演示算法行为。

## 合成示例（三种 w_late）

| w_late | 组 1/2/3 孕周（周） | 总成本 |
|---|---:|---:|
| 0.5 | 18.0 / 21.5 / 25.0 | 44.7 |
| 1.0 | 16.5 / 20.0 / 24.0 | 77.4 |
| 2.0 | 16.5 / 20.0 / 24.0 | 137.4 |

（合成数据：BMI 越高达标越慢；更高 w_late 倾向更早时点/成本结构变化——仅演示行为，无临床含义。）

## 实现要点

- 动态规划 O(n²·K·m)，n≤数百；周期间单调非降约束经“上一周前缀最小值”实现；覆盖率可行性按组均值检查，全部不可行时返回 infeasible（绝不静默放宽）。
- 纯 NumPy/Python，无新增依赖；随机性仅来自输入数据的生成（测试与示例固定种子）。
