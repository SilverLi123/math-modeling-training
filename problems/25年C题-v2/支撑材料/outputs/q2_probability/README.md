# Q2 观测达标概率：baseline 验证

已完成混合 Logistic 和固定达标率对比。当前结果不足以支持可靠的高概率时点推荐，因此尚未进入风险函数与 DP。这里的曲面是观察性、全数据拟合的探索结果，不是通过验证的最优检测策略。

## 模型和验证

- 男胎 1082 条记录、267 名孕妇，937 条记录 Y≥0.04。沿用 Q1 的五折孕妇划分。
- 输入仅为孕周和首次记录 BMI；按日期、孕周、样本序号排序取首次值，冻结后不随未来记录变化。首次 BMI 只是预约时 BMI 的代理，不能证明更早孕周时其值相同。首条记录不晚于 12 周者仅 69 人。
- 二项模型：`logit P(A_ij=1 | u_i)=β0+βt·标准化孕周+βB·标准化首条BMI+u_i`，`u_i~N(0,σ²)`。中心、尺度只用训练折计算。每名孕妇的重复测量通过随机截距处理，随机效应条件下假设记录独立。
- 用 Gauss–Hermite 求积对孕妇级 Bernoulli 似然积分，多个初值拟合并检查收敛，再加倍求积阶数检查精度。新孕妇概率同样积分未知随机效应，不借用本人检测结果，不把随机截距设零当作边际概率。
- 两个简单对照只用训练折：全部记录平均达标率、先按孕妇求平均再跨孕妇平均的达标率。无标签调参或验证折校准。

## 样本外结果

| 模型 | 记录 Brier | 孕妇等权 Brier | 记录 Log-loss | 孕妇等权 Log-loss |
|---|---:|---:|---:|---:|
| 混合 Logistic | 0.115400 | 0.111597 | 0.393783 | 0.383614 |
| 训练记录达标率 | 0.116402 | 0.113128 | 0.395480 | 0.386919 |
| 训练孕妇平均达标率 | 0.116298 | 0.113145 | 0.395033 | 0.387006 |

Brier 与 Log-loss 越小越好。主要按孕妇等权评价：先在每名孕妇内部平均损失，再跨孕妇平均。混合模型相对孕妇平均达标率的 Brier 差约 −0.001548；2000 次配对孕妇 Bootstrap 的 95% 区间为 [−0.006331, 0.002851]，跨零，未证明稳定优于简单对照。该 Bootstrap 仅重采样已冻结 OOF 误差，没有重拟合，不代表完整训练不确定性。

整体预测均值 0.86093 接近实际 0.86599，但不能据此认定校准良好：

- 预测在 [0.90,0.95) 的 250 条记录（153 名孕妇），平均预测 0.92404，实际仅 0.872。
- 预测在 [0.50,0.70) 的 17 条记录仅涉及 13 名孕妇，经验达标率很不稳定。
- 13–<16 周实际达标率 0.90991、预测 0.83083；16–<20 周实际 0.81132、预测 0.87508，时间校准方向不一致。
- 26–<30 周只有 9 条记录、8 名孕妇，不能把该组全达标当成可靠保证。

分箱结果为记录等权描述，同一孕妇可能出现在多个箱中；未使用假设记录独立的置信区间。重复检测的选择机制、同次测序依赖和遗漏个体特征仍是限制。随机效应与协变量独立等混合模型假设未被本实验完全验证。

3. [固定 BMI 概率切片](../figures/q2_probability/result_q2_probability_slices.png)：BMI=28/32/36 的示例切片，不是最终 BMI 分组；缺口表示局部支持不足。线形受当前线性 logit 规格约束，不应解释为已证明的单调生物规律。

`threshold_crossings.csv` 分别保存模型首次穿越和有局部支持的首次穿越，仅为概率水平的探索性读数，不是建议检测周。网格内未达到目标或支持不足时保留空值，禁止填为 25 周。BMI=32、36 在本次 11–25 周网格内均未达到 95%；不能据此外推更晚时点。

## 文件与复现

运行目录为题目根目录：

```powershell
.\.venv\Scripts\python.exe -W error src\run_q2_experiment.py
.\.venv\Scripts\python.exe -W error -m unittest discover -s src -p 'test_q2*.py' -v
```

入口输出 `comparison.csv`、`fold_metrics.csv`、逐行 `oof_predictions.csv`、两个校准表、`surface.csv`、`threshold_crossings.csv`、`experiment.json` 及三张图。`results/q2_probability_manifest.json` 绑定输入、代码、环境、本文及输出哈希。原始附件和 Q1 结果不变。

## 下一步判断

当前 baseline 已完成运行和验证，但尚不具备进入最终时点决策的证据。下一轮先在相同孕妇折内检查时间非线性及校准改善；若尝试重校准，也只能在训练折内部拟合。早期子样本敏感性、误差扰动及策略验证仍待后续；不能把本轮曲面当作这些分析的替代。
