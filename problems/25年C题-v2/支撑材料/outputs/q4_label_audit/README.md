# Q4 标签盘点（建模合同第一步）

女胎检测数据 605 行、147 名孕妇。独立抽样单位是孕妇；训练/验证按孕妇分组。

## 关键事实

- A_any（13/18/21 任一非整倍体）：阳性记录 67（11.1%），**独立阳性孕妇 44 人**，阴性 103 人。记录级阳性数明显大于主体级——重复采血/多次检测放大了记录数，建模评估必须以主体为独立单位。
- 类型标注为**无分隔符字符串**（例如 `T13T18`、`T18T21`），不能按逗号拆分；已用正则 `T13|T18|T21` 顺序无关地解析。
- 主体级类型组合：T18-only 19、T13-only 5、T21-only 6、T18+T21 1、T13+T21 3、T13+T18 8、三型兼有 2；跨行携带多型的主体 14 人。
- T13/T21 的独立阳性主体约 10 人量级：逐型独立建模须低维特征并明确报告不确定性；主性能展示采用 `A_any` 的直接模型，类型信息以计数与阈值化输出报告，不遗漏但也不夸大。
- 5 折主体分组可行（44 ≥ 5），具体分层分组在建模阶段执行并逐折核对类别覆盖。

## 类型级不确定性（不独立 CV 建模）

T13/T21 的独立阳性主体过少（每型 5~8 人），逐型 5 折 CV 的每折阳性数将低至 0~2 人，指标不稳定且易误导；因此**不**建立独立类型 CV 模型。类型级信息以主体流行率与 Wilson 95% 区间（n=147）报告：

| 类型（主体级） | 人数 | 流行率（95%CI） |
|---|---:|---:|
| A_any | 44 | 29.9%（23.1–37.8%） |
| T13（任一含 T13） | 8 | 5.4%（2.8–10.4%） |
| T18（任一含 T18） | 25 | 17.0%（11.8–23.9%） |
| T21（任一含 T21） | 8 | 5.4%（2.8–10.4%） |
| 仅 T18 | 19 | 12.9%（8.4–19.3%） |
| 仅 T13 / 仅 T21 | 5 / 6 | 3.4%（1.5–7.7%）/ 4.1%（1.9–8.6%） |
| 跨行多型（≥2 型） | 14 | 9.5%（5.8–15.4%） |

含义：任何关于 T13/T21 单独的“检出能力”断言在附件内都无法获得可靠样本外证据；主判据只能用 A_any 模型并如实报告其不确定性。
## 文件

- `audit.json`：全部计数与重叠、可行性。
- `label_counts.csv`：各标签阳性记录/阳性主体数。
- `subject_labels.csv`：主体级类型标志（T13/T18/T21、any）。
